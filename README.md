# Embedded Call for Swift
BEAM fork of element-call-swift (https://github.com/element-hq/element-call-swift). This fork contains modifications done by Belgian Secure Communications (BSC) for BEAM.

SwiftPM package containing an embedded build of the Element Call widget.

Please see the main Element Call repository for more information.

Any issues should be filed in the main repository.
